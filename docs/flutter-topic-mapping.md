# Original Burmese Flutter Curriculum Mapping

The public reference index organizes Flutter topics around introduction, installation, app creation, architecture, Dart, widgets, layouts, gestures, state, animation, platform-specific integration, packages, REST, database concepts, internationalization, testing, deployment, development tools, and advanced applications. The course will use this as a sequence reference only; it will not reproduce or translate the reference site's prose, examples, or page layout.

The existing curriculum already covers Dart fundamentals, widget layout, stateful forms, routing, responsive UI, REST, local storage, animation, architecture, testing, deployment, and a browser practice workflow. The expansion should add original Burmese chapters for: Flutter introduction and lifecycle, a simple first Flutter app, gestures and callback patterns, package evaluation, localization/accessibility, platform channels, development tools and debugging, and a capstone application workflow.

The official Flutter architecture overview reinforces the dependency order: app/root widget, widget tree and composition, state, layout/rendering, then platform integration. The added chapters should preserve that learning dependency order and use the platform's existing Step 1–5 pattern.
